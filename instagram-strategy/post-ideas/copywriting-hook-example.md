# Post idea — "Negative hook" copywriting rule (Arabic, single graphic)

Format: single 1080x1350 graphic (not a carousel). Teaches a copywriting
technique — the rule is stated first, then demonstrated with an example —
so it works as a standalone educational post for the marketing-tips pillar.

Design canvas: published separately (search your Claude Code artifacts for
"Noura Copywriting Hook Example").

## The rule (shown first, in a navy callout card)
> قول لعميلك "متشتريش" الأول... وخليه يكتشف السبب بنفسه.
> الهوك المعاكس بيوقف السكرول لأنه ضد المتوقع.

(Tell your customer "don't buy" first... and let them discover the reason
themselves. The reverse hook stops the scroll because it goes against
expectation.)

## The example (below the rule, tagged "مثال توضيحي" / illustrative example)
Big bold Arabic headline stack: "متشتريش / السيروم / ده", a serum-bottle
illustration, subhead "إلا لو عايز بشرة صافية وثابتة خلال ٢٨ يوم", and 3
checkmark benefits — recreating the visual language of a real "pattern
interrupt" skincare ad you shared as a reference, but built as **original
artwork with a fictional placeholder brand ("لمسة")** — not a copy of any
real product's packaging or branding. Safe to post as-is since it's clearly
marked as an illustrative example, not a real product claim.

## Caption draft
```
مبدأ من أقوى أساليب الكتابة الإعلانية: الهوك المعاكس.

بدل ما تقول لعميلك "اشتري"، قوله "متشتريش" الأول. ده بيوقف السكرول فورًا
لأنه ضد اللي دماغه متوقعه — وبعدين تدّيله السبب اللي هيخليه يشتري بنفسه.

المثال في الصورة توضيحي بس عشان تشوف الشكل — جرّبيه على منتجك أو منتج عميلك
وشوفي الفرق.

احفظ البوست ده لو بتكتب إعلانات بنفسك 📌
```
